# Glossary

**API** — Application Programming Interface. The backend's "doors" that the
website and app talk to.

**Escrow** — A neutral third party (the platform) holds funds until both
sides complete their obligations.

**JWT** — JSON Web Token. A signed string that proves a user's identity
after login.

**KYC** — Know Your Customer. The process of verifying a user's real
identity.

**MVP** — Minimum Viable Product. The smallest version that is useful
enough to launch and learn from.

**OTP** — One-Time Password. A short code sent via SMS used to verify a
phone number.

**PostGIS** — A PostgreSQL extension that adds geographic data types and
queries.

**Webhook** — An HTTP call a third-party service (like Paystack) makes to
your backend when something happens (like a successful payment).
